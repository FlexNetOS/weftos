## Items flagged for manual review

See [`MANUAL_REVIEW.md`](MANUAL_REVIEW.md). The two highest-priority issues:

1. **Rust MSRV contradiction (high priority).** `README.md` and
   `docs/deployment/release.md` declare Rust **1.93** as the toolchain.
   `docs/adr/adr-037-rust-edition-2024-msrv.md` states Rust **1.85** as the
   MSRV. `docs/architecture/wasm-browser-portability-analysis.md` references
   Rust **1.66** in a portability matrix. These three values must be
   reconciled before publishing.

2. **`gui/README.md` ↔ `clawft-ui/README.md` (Jaccard 0.82).** Two near-
   identical READMEs for what may be two different surfaces (an egui shell
   vs. the clawft UI). Confirm intent: are these the same product (merge
   READMEs) or two products (differentiate them).

## Methodology

The audit pipeline lives in
[`scripts/audit/detect_dups.py`](../../scripts/audit/detect_dups.py) and
[`scripts/audit/consolidate.py`](../../scripts/audit/consolidate.py). It is
deterministic and intended to run in CI to catch new duplicates.

## How RuVector is used

WeftOS does not embed RuVector as a runtime dependency for the audit, but
the n8n integration in [`scripts/n8n/`](../../scripts/n8n/) wires the WeftOS
knowledge base into a RuVector-compatible memory API for semantic retrieval.
See [`scripts/n8n/README.md`](../../scripts/n8n/README.md).
